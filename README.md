Steps:

1. Setup HTML file as index.html and stylesheet as style.css.
2. Within the target repository, go to settings. If repository is private, make it public.
3. Within settings, go to Pages and choose to deploy from a branch whilst choosing latest branch for the publishing source.
4. After pressing save, wait for a while in Actions for the website to be deployed.
5. Once finished, user can visit the site there with an accessible link.
6. Further commits will update the site from time to time.


Key Takeaway: Creating a website takes a lot of predictions to understand, especially in creating elements that will inevitably change due to the user's orientation. More knowledge were needed to use flex CSS well. Website creation was definitely confusing at first, but it simply needs one to follow its guidelines to comprehend immediately.
